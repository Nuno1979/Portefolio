### 🏢 **Sistema de Gestão de Reservas de Espaços — ESMAD/P.PORTO** (Power Apps)
**Professional automation system for room reservation management — Enterprise-grade solution built with low-code tools.**

- **Status**: ✅ Production • In Use
- **Technologies**: Microsoft Forms, Power Automate, Outlook, JSON
- **Period**: Professional Internship — ESMAD/P.PORTO
- **Focus**: Complete workflow automation, zero manual processing
- **Key Achievements**:
  - ✅ 100% automation of reservation process
  - ✅ Dynamic form with 6 conditional user profiles
  - ✅ Complex decision logic (22+ spaces, multi-tier approval)
  - ✅ Calendar integration with zero conflicts
  - ✅ < 1 minute end-to-end processing time
  - ✅ Fully scalable architecture

**The Challenge**: Build an automated system to manage room reservations for ESMAD/P.PORTO, supporting multiple space types (Galeria, Auditório, Other Rooms), different user profiles (Internal/External), and complex approval workflows.

**The Solution**: Designed and implemented a complete orchestration system using Microsoft Forms and Power Automate that:
- Captures structured data via dynamic forms with conditional sections
- Applies intelligent routing logic based on user profile + space type
- Auto-creates calendar events with conflict detection
- Sends personalized notifications
- Provides complete audit trails
- Scales to 22+ spaces without code changes

**Impact**:
- 📧 Eliminated manual email processing
- 📅 Zero calendar conflicts post-launch
- ⏱️ Reduced processing time from 24-48h to < 1 minute
- 🔄 Standardized workflows across all users
- 📊 Full auditability and traceability

**Technical Depth**: Built from scratch without prior Power Automate experience, mastering JSON parsing, conditional logic, variable management, and system integration in a production environment.
