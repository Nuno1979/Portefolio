- **Period**: Professional Internship — ESMAD/P.PORTO

- Provides complete audit trails
- Scales to 22+ spaces without code changes

**Impact**:

- 📅 Zero calendar conflicts post-launch
- ⏱️ Reduced processing time from 24-48h to < 1 minute
- 🔄 Standardized workflows across all users
- 📊 Full auditability and traceability

**Technical Depth**: Built from scratch without prior Power Automate experience, mastering JSON parsing, conditional logic, variable management, and system integration in a production environment.

### 🚀 **TechSolutions ETL Pipeline** (MySQL | Python | Power BI)
**Enterprise-grade data management and analytics system for AESHARE LDA — Complete ETL pipeline with real-time BI insights.**

- **Status**: ✅ Complete & Production-Ready
- **Client**: AESHARE LDA
- **Technologies**: MySQL, Python, Power BI, DAX
- **Period**: CESAE Digital Project — April 2025
- **Focus**: End-to-end data pipeline with multi-layer validation

**The Challenge**: Build a comprehensive data management system that enables efficient data governance while providing real-time business intelligence insights for decision-making.

**Architecture Layers**:
1. **Data Collection** - 1,200+ synthetic records from Faker, Fabricate, and AI
2. **Storage & Validation** - MySQL with stored procedures, triggers, constraints
3. **Transformation & Access** - Python CLI menu system with CRUD operations
4. **Visualization & Insights** - Power BI dashboard with advanced DAX measures

**Key Achievements**:
- ✅ 12+ normalized database tables with complex relationships
- ✅ Multi-layer validation framework (DB triggers, stored procedures, Python validation)
- ✅ 10+ custom DAX measures for KPI tracking
- ✅ 6 specialized Power BI dashboard pages
- ✅ 99%+ data accuracy with automated quality checks
- ✅ Python console interface for intuitive data management
- ✅ Real-time stock alerts and delivery tracking

**Database Components**:
- **Dimension Tables**: Cliente, Produto, Fornecedor, Funcionário, Departamento, Região de Venda
- **Fact Tables**: Vendas, Linha de Encomenda, Vendas Produto, Meta Categoria, Meta Funcionário
- **Advanced Features**: Age verification triggers, automatic stock updates, positive-value constraints

**BI Dashboard Features**:
- 👤 **Cliente** - Customer demographics & lifetime value
- 👔 **Funcional & Metas** - Employee performance vs. targets
- 🎯 **Metas de Categoria** - Sales targets & achievement tracking
- 📦 **Vendas** - Multi-dimensional sales analysis
- 📚 **Stock** - Real-time inventory management
- ⏱️ **Tempo de Entrega** - Delivery performance metrics

**Results**:
- 📊 Time Saved: ~15 hours/week (manual reporting elimination)
- 💾 Data Accuracy: 99%+ (quality assurance framework)
- 🚀 Processing Speed: Real-time insights vs. manual daily reports
- 🔐 Data Integrity: 3-layer validation ensuring consistency
